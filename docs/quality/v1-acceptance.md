Automated evidence is concentrated in `server/internal/*_test.go`, `server/tests/integration`, and `apps/web/src/*.test.ts`. The real-world procedure and invalid-evidence rules are defined in [`seven-day-child-trial.md`](seven-day-child-trial.md). The automated trial tests must never be cited as proof of child willingness.

The local browser E2E additionally proved role-aware password login and logout, real current-plan session creation, a wrong-answer Tutor transition, Parent child/session discovery without query parameters, private Parent projection, a server-authored encouragement intervention, Owner content/cost/trial rendering, and an empty browser warning/error log. The trial-record and voice-session browser fixtures were manually seeded UI evidence and are explicitly invalid as child-willingness or live-provider evidence. PostgreSQL tests additionally prove real activity-day growth data, support actions without answer-side effects, persisted emotion deescalation, independent-evidence mastery scores, and the complete cross-subject return loop. A separate authenticated HTTP field scan verified that Student session and question responses contain no private answer keys. These are local engineering results, not evidence of live provider quality or child retention.
