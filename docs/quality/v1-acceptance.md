Automated evidence is concentrated in `server/internal/*_test.go`, `server/tests/integration`, and `apps/web/src/*.test.ts`. Provider HTTP mocks exercise the real adapters and metering path, including rejected structured output. No live OpenAI request was made without deployment credentials and a matching Owner-approved price catalog. A real seven-day child trial is also outside engineering proof and remains required before a product-readiness claim.

The real-world procedure and invalid-evidence rules are defined in [`seven-day-child-trial.md`](seven-day-child-trial.md). The automated trial tests must never be cited as proof of child willingness.

The local browser E2E additionally proved role-aware password login and logout, real current-plan session creation, a wrong-answer Tutor transition, Parent child/session discovery without query parameters, private Parent projection, a server-authored encouragement intervention, Owner content/cost/trial rendering, and an empty browser warning/error log. A refreshed `VOICE_EXPLAIN` route recovered a persisted valid audio data URL and synchronized segments, played with the active segment highlighted, and returned through the server to the unchanged original released question. The trial-record and voice-session browser fixtures were manually seeded UI evidence and are explicitly invalid as child-willingness or live-provider evidence. PostgreSQL tests additionally prove real activity-day growth data, support actions without answer-side effects, persisted emotion deescalation, independent-evidence mastery scores, and the complete cross-subject return loop. A separate authenticated HTTP field scan verified that Student session and question responses contain no private answer keys. These are local engineering results, not evidence of live provider quality or child retention.
